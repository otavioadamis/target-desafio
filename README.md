# TargetDesafio

Projeto simples em C# com 5 desafios de lógica resolvidos. A aplicação roda no console e exibe os resultados diretamente no terminal.

## ✅ Requisitos

Antes de rodar o projeto, certifique-se de ter:

- [.NET SDK 6.0 ou superior](https://dotnet.microsoft.com/download) instalado
- (Opcional) Visual Studio ou Visual Studio Code

---

## ▶️ Como rodar o projeto

### ✔️ Via Visual Studio

1. Abra o Visual Studio
2. Clique em **"Abrir uma solução ou projeto"**
3. Selecione o arquivo `TargetDesafio.sln`
4. Clique no botão **"Iniciar" (Play)** ou pressione `F5`

---

### ✔️ Via Visual Studio Code

1. Abra o terminal e clone o repositório:

   ```bash
   git clone https://github.com/otavioadamis/target-desafio.git
   ```

   ```bash
   cd TargetDesafio
   ```
3. Abra o projeto no Visual Studio Code:

   ```bash
   code .

4. Para rodar o projeto:
- Usando o terminal:
  
  ```bash
  dotnet run

- Ou clicando em "Executar" no canto superior e escolhendo Program.cs
